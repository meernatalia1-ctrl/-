# Система обессоливания нефти  Анимированная демонстрация работы установки обессоливания нефти по патенту Республики Казахстан № 12868 (полезная модель).  Анимация показывает путь нефти через установку: насос, подогреватель, смеситель (нефть, промывная вода и деэмульгатор), электростатический обессоливатель и горизонтальный отстойник.
